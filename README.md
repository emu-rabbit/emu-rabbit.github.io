# 兔子的窗邊手記

這裡是 `emu-rabbit.github.io`，也是絵夢羽さ沂放在窗邊的一本小小手記。

如果你剛好經過，可以往裡面看見一隻白色垂耳兔。她在人類社會裡生活、寫程式、存錢、約會、玩遊戲，也慢慢練習用更自由、更誠實的方式理解自己。

網站目前在這裡：

[https://emu-rabbit.github.io/](https://emu-rabbit.github.io/)

## 這個網站在做什麼

這是一個很輕的個人自我介紹網站。

它想讓來到這裡的人知道：絵夢羽さ沂是誰、她在意什麼、她怎麼生活、怎麼工作，也怎麼把那些有點柔軟、有點任性、有點不容易被標準分類收好的部分，安放在一個可以被靠近的頁面裡。

所以這裡有一些身體裡的小註記，有討生活的程式設計，有 Final Fantasy XIV、Minecraft、存錢和約會，也有關於愛、自由、誠實，以及仍然想走向真實之處的那條路。

它像一扇被留著縫隙的窗。裡面沒有急著把故事講完，只是把一些足夠重要的片段，先溫柔地放在光裡。

## 關於這隻兔子

絵夢羽さ沂是一隻在人類社會生活的台灣本土兔子。

她害怕寂寞，卻還是想勇敢地去愛。她渴望自由，也渴望誠實；不太喜歡把自己塞進太乾淨的分類裡，但很願意慢慢說清楚自己是什麼樣子。

她靠程式設計討生活。程式對她來說是冰冷的邏輯和數字，可是它可以長成溫暖的文字、改善生活的小工具，或是讓人會心一笑的作品。這件事很迷人，所以她一直做著。

她也喜歡生活裡那些比較私人、比較有溫度的東西：一起吃飯、逛街、過夜、隔天早餐，遊戲裡緩慢但認真地生活，還有把錢存下來、看懂自己正在往哪裡去。

## 這個 repo 的氣味

這個 repo 裝著這扇窗背後的材料：HTML、CSS、TypeScript、圖片、字體，以及一些讓頁面慢慢長成現在模樣的小決定。

它希望保持輕量、安靜、好維護，也希望每一次修改都能繼續照顧那種溫柔、自由、舒服、親近的感覺。文案、照片、字體、背景與小互動，會一起讓人更理解她。

目前技術上使用 Vite + TypeScript，核心內容盡量放在 HTML 裡，讓頁面可以很快被看見。JavaScript 只做少量漸進增強，例如語言切換與互動細節。

## 如果你想在本機打開窗

```powershell
npm install
npm run dev
```

正式輸出：

```powershell
npm run build
```

這個專案有自訂字體 subset 與靜態資產處理，所以 build 時會先跑字體腳本。若你只是在 GitHub 上路過，知道這是一個用很多小心意慢慢搭起來的個人靜態站，就已經足夠了。
